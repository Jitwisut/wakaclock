# Shadcn UI Kit

A large collection of admin dashboards, website templates, UI components, and
ready-to-use blocks. Save time and deliver projects faster.

This is a [Next.js 16](https://nextjs.org/) project using React 19 + TypeScript,
with Storybook 10 for component development.

## Installation

Follow these steps to get your project up and running locally:

1. Install dependencies:

   ```sh
   npm ci
   ```

2. Run the development server:

   ```sh
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser to view
   the result.

## Common commands

```sh
npm run lint:strict
npm run typecheck
npm run test:run
npm run validate
```

Storybook:

```sh
npm run storybook
npm run storybook:test
```

E2E tests:

```sh
npm run test:e2e
```

## Minimum system requirements

- Node.js version 20 and above.

Note: If you experience problems with versions above Node.js v20, please replace
with version v20.
